# Моя валентинка

Одностраничная валентинка по мотивам [видео из TikTok](https://vt.tiktok.com/ZSgREuQbD/).
Открывается по ссылке на телефоне — ничего ставить не надо.

**Живая версия:** https://garist0308.github.io/valentine/

## Как это устроено

Четыре экрана подряд:

1. «Машенька, ты меня любишь?» — кнопки «Да!» и «Нет»
2. «Ты уверена?» — только «Нет»
3. «Ты меня любишь?????» — только «Да!»
4. Котик с сердечком и «Машенька, я тебя тоже люблю))!»

Кнопка «Нет» на первом экране **убегает три раза**. На телефоне она ловит
касание в момент `pointerdown` — то есть раньше, чем тап превратится в
нажатие, — и перепрыгивает в случайную точку экрана. На четвёртый раз даёт
себя поймать, и начинается второй экран. На десктопе то же самое срабатывает
на подведение курсора.

Места приземления выбираются так, чтобы кнопка не вылезала за экран, не
закрывала заголовок и не накрывала кнопку «Да!».

## Файлы

```
index.html        вся страница: разметка, стили и скрипт в одном файле
img/cat-1.png     котик машет лапкой
img/cat-2.png     котик плачет
img/cat-3.png     котик умоляет
img/cat-4.png     котик обнимает сердечко
```

Картинки сгенерированы ИИ одним изображением (сетка 2×2, чтобы котик был
одинаковым во всех состояниях) и нарезаны на четыре файла.

## Поменять имя или текст

Всё лежит прямо в `index.html` — четыре секции `<section class="screen">`.
Количество побегов кнопки — константа `DODGES` в скрипте.
